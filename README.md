## Featured project

### EDP — ESR Disc Patcher

![GPL-3.0](https://img.shields.io/badge/license-GPL--3.0--or--later-blue)
![Python 3.9+](https://img.shields.io/badge/python-3.9%2B-3776AB?logo=python&logoColor=white)
![Runtime deps: 0](https://img.shields.io/badge/runtime%20deps-0-success)

Turn **your own** PS2 game backups into discs the console boots — **no modchip**.
EDP touches only the disc descriptors and embeds the **ESR + FreeDVDBoot** boot
path, leaving the game byte-for-byte untouched. Pure Python, standard library
only, CLI + GUI, validated on real hardware.

→ **[Repository](https://github.com/Dougwan/ESR-Disc-Patcher)**
